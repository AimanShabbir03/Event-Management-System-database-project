# Event Management System – Database Management System

## 📌 Project Overview

The **Event Management System** is a Database Management System project designed to manage and organize different aspects of event planning and management.

The system provides functionality for managing users, events, attendees, vendors, tasks, budgets, resources, payments, feedback, sponsors, media, invitations, schedules, and contact messages.

This project demonstrates practical concepts of **Database Design, ERD, Normalization, SQL, CRUD Operations, Joins, Nested Queries, and Aggregate Functions**.

## 🎯 Objectives

* Design a structured and efficient event management database.
* Manage event-related information in a centralized system.
* Perform CRUD operations on database records.
* Implement SQL joins and nested queries.
* Use aggregate functions for data analysis.
* Apply database normalization up to **3NF/BCNF**.
* Provide a simple frontend interface for interacting with the system.

## 🛠️ Technologies Used

* **Database:** SQL
* **Backend:** Node.js
* **Frontend:** React.js
* **Database Concepts:** ERD, Normalization, CRUD, Joins, Nested Queries, Aggregate Queries

## 🧩 Database Design

The database was designed using an **Entity Relationship Diagram (ERD)** to define relationships between different entities.

Database normalization was applied to reduce redundancy and improve data consistency, including:

* First Normal Form (1NF)
* Second Normal Form (2NF)
* Third Normal Form (3NF)
* BCNF

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/AimanShabbir03/Event-Management-System-database-project.git
```

### 2. Navigate to the Project

```bash
cd "Event-Management-System-database-project/Database Project/Event Management System"
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Backend

```bash
node server.js
```

### 5. Run the Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```
